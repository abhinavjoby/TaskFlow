meet the team

Traditional to-do lists fail to address decision fatigue and the lack of dynamic urgency. TaskFlow solves this by replacing static lists with a computational scheduling engine that uses a Min-Heap priority model and real-time focus detection. Our novelty lies in bridging high-performance Python logic with a modern web interface to align task management with the user's actual cognitive state.
